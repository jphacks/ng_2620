# ADR-0015 Tauri を廃止し、Windows 専用のローカル Web サーバー＋ブラウザ UI にする

- 状態：採択
- 日付：2026-10-25
- 置換：[ADR-0001](0001-desktop-framework-tauri.md)

## 文脈
- ADR-0001 では Tauri 2 のデスクトップアプリを採択した。Rust 側はファイル操作・子プロセス・HTTP などの OS 機能だけを持たせる方針だった。
- 推論は CUDA 前提で、実行できるのは NVIDIA GPU のある Windows 機に限られる（[ADR-0002](0002-gpu-server-and-compute-backend-port.md)）。CUDA 環境のないユーザーは、外部の GPU サーバーに接続するしかない。
- 配布を考えると、Tauri（Rust ビルド・WebView2 差異・署名）の負担に対して、デスクトップアプリであることの利点が小さい。UI はすでに Web 技術（React）で書かれている。

## 決定
1. **Tauri を廃止**する。Windows アプリは UI を持たず、**ローカル Web サーバーを同梱**する。操作はブラウザで行い、操作感は現行の Tauri 版を移植する。
2. サーバーの実装言語は **Python**。既存の `services/gpu_server`（FastAPI）を拡張し、ローカルアプリサーバーにする。Rust は使わない。
3. ローカルサーバーは **SPA も配信**する。GitHub Pages に公開するビルドと同一のものを使う。待受は `127.0.0.1` に限り、起動トークンで保護する。
4. **GitHub Pages（グローバル公開）＋外部 GPU サーバー**で、CUDA のないユーザーもブラウザから使えるようにする。ローカルサーバーが無いので機能は制限する（制限モード）。
   - ローカルファイルへの直接アクセスは使えない。保存はプロジェクトの zip のダウンロード／アップロードで行う。
   - 外部 GPU は **BYO**（利用者が用意する）。運営側のホストは持たず、認証は利用者自身の Bearer トークンで、コストは利用者が負担する（#35 で決定済み）。
5. 配布は**薄いインストーラー＋初回ブートストラップ**。Python 環境・torch・重み（約 7GB）は初回起動時に取得する。
6. 対象 OS は **Windows（RTX）のみ**。macOS はモックサーバーまたは外部接続で画面だけを動かす（開発用途）。

## 却下した案
| 案 | 却下理由 |
|---|---|
| Electron 継続（デスクトップアプリのまま Tauri から移行） | UI を持つデスクトップアプリである限り、配布サイズ・署名・更新の負担が残る。ブラウザで足りる操作しかなく、同梱する意味が薄い |
| C#（WPF / WinUI など）で作り直す | UI をすべて書き直すことになり、既存の React 資産を捨てる。Python のパイプラインとも別言語になる |
| File System Access API 中心（サーバー無しでブラウザだけ） | Chromium 系限定で、巨大ファイルの扱い・原子的書き込み・ffprobe や sha256 の計算・GPU ジョブの起動をブラウザだけでは賄えない。制限モードの範囲にだけ使う |

## 影響
- ADR-0001 の状態を `置換済み（ADR-0015）` にする。
- [ADR-0002](0002-gpu-server-and-compute-backend-port.md)：「Windows ではアプリが子プロセスとしてサーバーを起動する」を「ランチャーがローカルサーバーを起動する」に読み替える。`ComputeBackendPort` の構成は変わらない。
- [ADR-0012](0012-transport-and-auth.md)：項目 5（Tauri の CSP／`tauri-plugin-http`）は無効になる。代わりに、ブラウザからの外部 GPU 接続のために **HTTPS・CORS・トークン必須化**が要る（#36）。
- [ADR-0013](0013-frontend-stack.md)：ビルドの「Tauri 2 の標準テンプレート」は根拠でなくなる。Vite のままとし、Pages 用の base パスに対応する。
- [ADR-0014](0014-server-stack.md)：FastAPI＋サブプロセス実行の方針は変わらない。ローカル FS API・media/hash API・SPA 配信が加わる。
- ファイル操作・ハッシュ計算・ffprobe など、これまで Rust が担っていた機能はローカルサーバーの API に移す。
- 大きなファイルを asset プロトコルで読む方式（ADR-0001）は、ローカルサーバーの範囲読み（Range）に置き換える。

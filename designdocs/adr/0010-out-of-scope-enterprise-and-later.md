# ADR-0010 エンタープライズ機能・多形式書き出し等は今回の 2 日間ではスコープ外とし、拡張点だけ残す

- 状態：採択
- 日付：2026-10-24

## 文脈
- 製品の将来像はエンタープライズ（Adobe 系）のデスクトップ製品。ただしハッカソンは 2 日間で、デモは Mac 上の単一ユーザー。
- 「将来を見据えた設計」は要るが、「完全に再現する必要はない」（要件）。

## 決定
以下は**今回の 2 日間の開発ではスコープ外であり、本実装は行わない**。設計上の拡張点（ポート・スキーマのフィールド・API のパス予約）だけを残す。

| 項目 | 本実装で必要になるもの | 今回残す拡張点 |
|---|---|---|
| ユーザー認証・SSO（SAML / OIDC） | IdP 連携、トークン更新、サーバー側のユーザー管理 | API は `Authorization: Bearer` 必須（今回は固定トークン）。`/v1/me` を予約 |
| チーム・権限・共有 | 組織・ロール、プロジェクトの所有者と共有、共同編集の競合解決 | `project.json` に `owner` / `createdBy` を予約（今回は空） |
| ライセンス（席）管理・課金 | ライセンスサーバー、オフライン猶予、使用量計測 | サーバーがジョブごとの GPU 秒を記録（観測用） |
| 監査ログ・データ保持ポリシー | 誰が何をいつ処理・閲覧・削除したか、保持期間と自動削除 | サーバーのジョブ記録（開始・終了・入力のハッシュ）。`DELETE /v1/projects/{id}` |
| オンプレ / VPC 配備の運用 | コンテナ化、GPU スケジューラ、監視、SLA | サーバーは設定を環境変数で受ける。ステートは `VVLOG_DATA_ROOT` 配下のみ |
| 署名・公証・自動更新・インストーラ | Apple Developer ID、Windows コード署名、更新配信 | なし（デモは開発ビルド） |
| 書き出し形式の拡充 | ProRes 4444 / PNG 連番 / レイヤー別 / VRMA・BVH / Premiere・AE 連携 | `export` ジョブの `format` を列挙型にし、`mp4_h264` のみ実装 |
| 人物の消去・ぼかし（匿名化） | キャストの操作種別、除去のみのレンダリング | `CastEntry.action` を列挙型にし、`replace` のみ実装 |
| 途中から入る人物、180 秒超、4 人超 | 検出の再実行、チャンク処理 | `analyze` のパラメータに `maxTargets` / `segment` を予約 |
| Mac でのローカル推論 | MPS / Core ML への移植（SAM3 等） | `ComputeBackendPort` の別アダプタとして追加可能 |
| VRoid Hub 連携 | OAuth、利用条件の確認フロー | `AvatarSource` に `vroid_hub` を予約 |

## 影響
- デモと PRD では、上記を「将来の製品形」としてロードマップに示す（[PRD §8](../PRD.md#8-スコープ外今回の-2-日間では実装しない設計上の拡張点だけ残す)）。
- 予約したフィールド・パスは契約に含めるが、今回は未実装（`501 Not Implemented`）でよい。

# VirtualTwin ロゴ アセットガイドライン

VirtualTwin のロゴ一式の使い方をまとめたもの。ロゴの正（ソース）はこのフォルダの **SVG**。PNG は書き出し物。

## 1. コンセプト

- 2 つの丸い子が重なっている。**白い子 = 隠したい自分**、**黄色い子 = なりたい自分**（アバターに置き換わった姿）。
- 黄色い子が白い子に重なって、白い子が少し欠けて見える。「アバターが前に出る」関係を表している。
- 名前の頭文字を、顔のパーツにさりげなく隠している（文字ロゴ！という見せ方はしない）。
  - 白い子の鼻 = **T**、黄色い子の口 = **V**。
- 雰囲気は「ゆるふわ・ポップ」。色は緑（メイン）と黄色（サブ）、白。

## 2. ファイル一覧

### 2.1 ディレクトリ構成

版ごとにフォルダを分け、その中を `svg/`（正）と `png/`（書き出し）に分けている。

```
brand/
  README.md                このガイドライン
  color/        カラー版（白・明るい背景用）
    svg/  png/
  color-dark/   カラー版の暗い背景用（反転版）
    svg/  png/
  mono-black/   モノトーン黒（白・明るい背景用）
    svg/  png/
  mono-white/   モノトーン白（暗い背景用。モノトーンの反転版）
    svg/  png/
```

どの版も、中身は同じ 5 種類のロゴ。ファイル名は `virtualtwin-<種類><版の印>.svg|png`。

| 版 | 版の印 | 例 |
|---|---|---|
| カラー | なし | `color/svg/virtualtwin-logo-horizontal.svg` |
| カラー（暗い背景用） | `-dark` | `color-dark/svg/virtualtwin-logo-horizontal-dark.svg` |
| モノトーン黒 | `-mono-black` | `mono-black/svg/virtualtwin-logo-horizontal-mono-black.svg` |
| モノトーン白 | `-mono-white` | `mono-white/svg/virtualtwin-logo-horizontal-mono-white.svg` |

### 2.2 ロゴの種類

| ロゴ | ファイル名（種類の部分） | 用途 | PNG のサイズ（透過） |
|---|---|---|---|
| 正方形マーク | `mark` | アプリアイコン、SNS アイコン、ファビコン元 | 1024px 角 |
| 文字ロゴ | `wordmark` | 幅が取れる場所、ヘッダーなど | 2400px 幅 |
| 横並び | `logo-horizontal` | ヘッダー、スライドのタイトル、README の見出し | 2400px 幅 |
| 縦並び | `logo-vertical` | 表紙、ポスター、ステッカー、幅の狭い場所 | 1600px 幅 |
| 丸だけ（部品） | `mark-circles` | 横並び・縦並びの部品。単体でも使える | 1024px 幅 |

### 2.3 版の使い分け

| 背景 | カラーを使う | 単色を使う |
|---|---|---|
| 白・明るい背景 | `color/` | `mono-black/` |
| 暗い背景・暗い写真の上 | `color-dark/` | `mono-white/` |

- **color-dark（暗い背景用）**: カラー版から、影（暗い背景では見えない）を外しただけの版。色や形は同じ。正方形マークは、緑の板があるので暗い背景でもそのまま使えるため、カラー版と同じ内容。
- **モノトーン**: 黒と白の 2 色（`#111111` / `#FFFFFF`）。色ではなく形で白い子・黄色い子を描き分けている。
  - 白い子 = 輪郭線だけ。顔は塗り。
  - 黄色い子 = ベタ塗り。顔は抜き。
  - 文字ロゴ = 抜き文字を 1 本の縁取りで囲む。i の玉は、左（白い玉）が無地、右（黄色い玉）が輪付き。
  - 正方形マークは、角丸の板を単色で塗り、中の 2 つの丸を抜いて表している。
  - 抜いた部分は、背景の色が透けて見える（透過）。白版を透過 PNG のまま白背景に置いても見えない。

迷ったら次の順で選ぶ。

1. 正方形の枠に入れる → **正方形マーク**
2. 横に長い場所 → **横並び**
3. 縦長・正方形に近い場所で名前も見せたい → **縦並び**
4. 名前だけ必要で、マークが近くに別にある → **文字ロゴ**

## 3. カラー

### 3.1 正方形マーク

| 要素 | 色 |
|---|---|
| 背景（グラデーション、左上→右下） | `#7BEBA6` → `#2DBE6C` → `#128A48` |
| 白い子 | `#FFFFFF` 〜 `#DDF3E6`（球のグラデーション） |
| 黄色い子 | `#FFE57A` → `#FFC93C` → `#FFAE1A`（球のグラデーション） |
| 顔のパーツ | `#14532D` |
| ほっぺ | 白い子 `#FFB3A7`、黄色い子 `#FF9F6B`（ともに不透明度 75%） |

### 3.2 文字ロゴ（丸だけの部分を含む）

| 要素 | 左「Virtual」 | 右「Twin」 |
|---|---|---|
| 背景（縁取り） | `#52D08B`（外側の線 `#1FA05F`） | `#FFDB5A`（外側の線 `#EDAA14`） |
| 文字 | 白（下に向かって薄く `#DDF6E9`） | 白（下に向かって薄く `#FFEDB0`） |
| 文字の輪郭線 | `#1C9A5A` | `#E89C0C` |
| i の玉 | 白い玉 | 黄色い玉 |
| 影 | `#3F8F68`（不透明度 22%） | 同左 |
| 顔のパーツ | `#1F6841` | 同左 |

### 3.3 丸だけ（部品）

白い背景でも白い子が見えるよう、白い子に緑の線 `#1FA05F`、黄色い子に濃い黄の線 `#E89C0C` を付けている。線の太さはどちらも 6（512 の座標系）。

## 4. 余白（クリアスペース）

ロゴの周りには、**黄色い子の直径の 1/4**以上の余白を空ける。余白には文字・画像・他のロゴを置かない。

## 5. 最小サイズ

実際の見え方を細かくは検証していないため、目安として扱う。小さくして読めなくなったら大きくする。

| ロゴ | 最小サイズの目安 |
|---|---|
| 正方形マーク | 48px 角（それ未満は背景の細かい効果が潰れる） |
| 文字ロゴ | 幅 160px |
| 横並び | 幅 240px |
| 縦並び | 幅 160px |

## 6. 使ってよい背景・使ってはいけない使い方

### 6.1 背景

- カラーの基本は **白、または明るい背景**（`color/`）。
- 暗い背景では、`color-dark/` か `mono-white/` を使う。
- 中間の明るさの背景（鮮やかな緑・黄色など）では、ロゴの縁取りと背景が同化しやすいので、避けるか、白い板の上に置く。

### 6.2 やってはいけないこと

- 色を変える（左右の緑・黄色を入れ替える、別の色にするなど）。
- 縦横比を変えて引き伸ばす。傾ける、回す。
- 白い子と黄色い子の重なり方・左右の位置を変える。
- 文字ロゴの左右（緑／黄色）の分け方を変える。
- 影や縁取りを足す、外す、ぼかす。
- 写真や模様の上に直接置いて、見えにくくする。
- 正方形マークの背景（緑）を取って丸だけにして、正方形マークとして使う（丸だけは横並び・縦並びの部品）。

## 7. 書き出し・形式

- 配布・編集は **SVG**。PNG は、SVG が使えない場所（SNS、スライドなど）向け。
- PNG は透過。サイズは §2.2 の表のとおり。別サイズが要るときは SVG から書き出す。
- **デスクトップアイコン用の複数サイズ**: `color/png/mark-sizes/virtualtwin-mark-<サイズ>.png`（16 / 32 / 48 / 64 / 128 / 256 / 512 / 1024px 角、正方形マークのカラー版のみ）。
  - 角は丸めた状態で透過になっている。OS が自分で角を丸める用途（iOS など）には、そのままでは使えない（§9）。
  - 16px は細部が潰れて、白と黄色の丸が並んでいるのが分かる程度になる。
  - Tauri（`apps/desktop/src-tauri/icons/`）に使うときの対応: `32x32.png` = 32、`128x128.png` = 128、`128x128@2x.png` = 256、`icon.png` = 512 または 1024。`icon.ico`（Windows）は `color/icon/virtualtwin.ico`、`icon.icns`（macOS）は `color/icon/virtualtwin.icns` を、名前を `icon.ico` / `icon.icns` に変えて使う。
  - `virtualtwin.ico`: 16 / 32 / 48 / 64 / 128 / 256px の 6 サイズ入り（各サイズ PNG 形式で格納）。
  - `virtualtwin.icns`: 16〜1024px（標準の `@2x` 込み 10 枚）入り。macOS の `iconutil` で、`mark-sizes/` の PNG から作成。
- SVG には、グラデーション、マスク、クリップが入っている。3・4 の SVG は、文字ロゴと丸だけを入れ子で組んでいる。
- Illustrator で開くと、グラデーションやマスクの見え方、グループの扱いが少し変わることがある。編集したいときは、まず開いて見た目を確認する。

## 8. 書体・ライセンス

- 文字ロゴは、Arial Rounded Bold（macOS 標準）を元に、文字の形をアウトライン化して作っている。フォントの指定は不要。
- **商用・配布物にロゴを使う前に、このフォントのライセンスを確認すること。** 確認が取れない場合は、別のフォント（ライセンスが明確なもの）で作り直す。

## 9. まだないもの（今後の課題）

- 暗い背景用のカラー版の作り込み（今は影を外しただけ。暗い背景の上でさらに映えるよう、縁取りや文字の色を調整する余地がある）。
- 単色版の細部の検証（刺繍やスタンプなど、細い線が使えない用途では、文字の縁取りや顔の線を太くする調整が要るかもしれない）。
- アプリアイコン用の、角を丸めない正方形版（iOS など OS が角を丸める場合）。
- ファビコン用の、細部を省いた小さいサイズ専用の版。
- 実際の見え方を確かめる、最小サイズの検証。
- 図形を正円・楕円のまま保った SVG（今の SVG は魚眼効果の都合で、図形の一部が細かい線の集まりになっている）。

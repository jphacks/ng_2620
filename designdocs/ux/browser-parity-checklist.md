# Tauri 版 → ブラウザ版：操作感の差分チェックリスト

[ADR-0015](../adr/0015-web-first-windows-local-server.md) で Tauri のデスクトップアプリをやめ、ブラウザ＋ローカルサーバーにした（#39）。
「操作感は現行の Tauri 版を移植する」という方針に対して、どこが同じで、どこが変わったか、何を自動で確かめ、何を人が確かめるか。

- 自動：`apps/desktop/e2e/`（Playwright。Chromium と WebKit。モックサーバーで GPU なし）／`pnpm test`（vitest）
- 対象ブラウザ：**Chrome / Edge と Safari（Mac）を保証**。Firefox は動けば可（保証なし）（#28）
- 凡例：✅ 同じ／🔁 変わったが代替あり／⚠️ 変わった・制約あり／❌ 今回は提供しない　｜　自動＝E2E・vitest が確かめている／手動＝人が実機で確かめる

## 1. 主要フロー

| フロー | Tauri 版 | ブラウザ版 | 状態 | 確かめ方 |
|---|---|---|---|---|
| 起動 | アプリのアイコンから | ランチャーがサーバーを起動し、既定ブラウザで `http://127.0.0.1:PORT/` を開く（#31） | 🔁 | 手動（Windows。ランチャー未実装） |
| 動画の取り込み（ドロップ） | ウィンドウへドロップ → パスを得る | ドロップ → **サーバーの取り込みフォルダへ転送**（進捗つき・中止可）→ サーバー上のパスで扱う。受け付けない先には送らない | 🔁 | 自動（full-mode）／巨大ファイルは手動 |
| 動画の取り込み（選択） | OS のファイルダイアログ | **サーバー側の Windows ネイティブダイアログ**（ブラウザの背面に隠れない）。ローカル接続のときだけ | 🔁 | 手動（Windows。Linux では 501 を確認） |
| 動画の情報（長さ・fps・音声） | 同梱の ffprobe | サーバーの ffprobe。無ければ `<video>` で代用 | ✅ | 自動（`30fps / 音声あり` が出る） |
| 解析 → 人物の一覧 | ジョブ・SSE・段階的プレビュー | 同じ（`fetch` のストリーム） | ✅ | 自動 |
| キャスト → 描画 → エディタ | 同じ | 同じ | ✅ | 自動（アバター取り込み〜エディタ） |
| 書き出し（MP4） | 保存先を選んで保存 | サーバーのプロジェクトの `exports/` に保存（保存先の指定は今回なし。制限モードはブラウザのダウンロード） | ⚠️ | 自動（`exports/*.mp4` ができる） |
| 保存・再開 | フォルダ形式 `*.vvlog/`、自動保存 | 同じ（フルモード）。制限モードは IndexedDB ＋ **zip の書き出し／読み込み** | ✅／🔁 | 自動（開き直し・zip 往復） |
| 最近のプロジェクト | 一覧・Finder で表示 | 一覧は同じ。『エクスプローラーで表示』は**今回は見送り**（制限モードは『zip で保存』） | ⚠️／❌ | 自動 |

## 2. 入力・ウィンドウ

| 項目 | Tauri 版 | ブラウザ版 | 状態 | 確かめ方 |
|---|---|---|---|---|
| ショートカット | `⌘/Ctrl` + `S`・`O`・`,`・`J`・数字 | 同じ。ページが先に取る（`preventDefault`） | ✅ | 自動（`Ctrl+,`・`Ctrl+J`・`Ctrl+S`） |
| 新規プロジェクト `⌘/Ctrl+N` | 新規 | **ブラウザの新しいウィンドウに取られる**（Chrome の予約キー）。代わりに `⌘⌥N` / `Ctrl+Alt+N` | ⚠️ | 自動（キー表記）／実機は手動 |
| macOS の `⌥` + 文字 | — | 文字が変わる（⌥N → ˜）ので、文字キーは物理キーで判定する | 🔁 | 自動（vitest） |
| ウィンドウ・タイトルバー | 専用ウィンドウ、信号機ボタン | 既定ブラウザの**通常のタブ**（PWA 化はしない）。画面の上部バーはアプリ内のもの | ⚠️ | — |
| 右クリックメニュー | Radix の ContextMenu | 同じ | ✅ | 自動（zip で保存） |
| 最小サイズ | 1280×800 | 画面の `min-width: 1280px`。それより狭いと横スクロール | ⚠️ | 手動 |
| 戻る・進む・リロード | アプリには無い | ブラウザの機能がある。`#` ルーティングなので戻るで画面が戻る。リロードしても保存済みなら続きから | 🔁 | 自動（開き直し） |
| 複数タブ | 1 ウィンドウ | 同じプロジェクトを 2 つのタブで開くと、後から保存したほうが勝つ | ⚠️ | 手動（既知の制約） |

## 3. 通知・システム

| 項目 | Tauri 版 | ブラウザ版 | 状態 | 確かめ方 |
|---|---|---|---|---|
| 完了通知 | OS 通知 | Web Notifications（許可時のみ。許可はボタンの中で求める＝Safari 必須）＋画面内トースト＋**タブのバッジ ●** | 🔁 | 自動（ロジック）／実機の通知は手動（3 ブラウザ） |
| 外部ファイルを開く | OS の既定アプリ | ブラウザの新しいタブ（VRM の利用条件の URL など） | 🔁 | — |
| トークンの保存 | 設定フォルダ（権限 600） | フルモード：同じ（サーバー側）。制限モード：IndexedDB（ブラウザ内） | 🔁 | 自動 |
| この PC の GPU | アプリが子プロセスで起動・停止 | サーバー＝アプリ自身。接続『この PC』が**自動登録**（編集・削除不可） | 🔁 | 自動 |

## 4. 制限モード（Pages）にしかないもの

| 項目 | 内容 | 確かめ方 |
|---|---|---|
| 案内バナー | 消えうること・zip で保存・ローカルアプリの利点 | 自動 |
| 外部 GPU の登録・診断 | URL とトークンを登録。届かない理由（混在コンテンツ／CORS／届かない）を案内 | 自動（CORS と届かないを実ブラウザで） |
| 送信先の確認 | 外部サーバーへ初めて動画を送るとき | 自動 |
| 元の動画の選び直し | 別の PC で作られた zip は元の動画が無い。sha256 で同じ動画か確かめる | 自動 |
| ローカルアプリを探す／開く | Chrome／Edge は探せる。Safari・Firefox はアドレスの案内だけ | 自動（ロジック）／https のページからの実機は手動 |
| Safari の IndexedDB | 一定期間操作が無いと消えうる → zip で保存を促す | 手動（再現は難しい） |

## 5. まだ人が確かめる必要があるもの（このリポジトリの環境では確かめられなかった）

1. **Windows 実機**：ネイティブダイアログの表示と前面化、ランチャー、インストーラー、ffprobe の同梱。
2. **WebKit（Safari）**：Playwright の WebKit は CI（`--with-deps`）で回す。手元の Linux では依存ライブラリが足りず起動できなかったので、**初回は CI の結果を確認**する。Safari 実機での通知・IndexedDB・ダウンロードも。
3. **H.264 の再生**：Playwright 同梱の Chromium は H.264 を再生できないため、`<video>` のプレビューと、制限モードの『動画のドロップ → ブラウザ側の probe』は E2E で通せない（代わりに zip の読み込み → 動画の選び直しで通している）。Chrome／Edge／Safari の実機では再生できる想定。
4. **https の Pages → `http://127.0.0.1`**（Chrome のローカルネットワークアクセスの許可）。
5. **巨大ファイル**（数百 MB）のドロップ転送・IndexedDB への書き込みの実測。

## 6. 差分を見つけたら
このチェックリストに行を足し、直すなら Issue を切る。『同じ』にできないものは、理由と代替をここに書いておく（機能差分表 [mode-matrix](../features/mode-matrix.md) と対にする）。

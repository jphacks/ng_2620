# デモ台本（目安 5 分）

環境：MacBook（Apple Silicon）＋ vvlog（開発ビルド）。GPU サーバーはチームの Windows 機（RTX）を Tailscale で公開したもの。このデモ用 Mac を同じ tailnet に参加させて接続する。
前日までに：重みの配置、サーバー起動確認、デモ用ジョブの事前実行、サンプルプロジェクトの同梱、書き出し済み動画の用意。

## 0. 事前準備（開始 30 分前）

- [ ] Mac と Windows 機の両方で Tailscale が接続中。Mac から `https://<機名>.<tailnet>.ts.net/v1/health` が通る（会場のネットワークで）。キューが空。
- [ ] プロジェクト A「完成済み」：解析・描画まで完了し、手修正は**未適用**（デモで直す箇所を 1 つ決めておく：例 フレーム 120 のギターがアバターの後ろに描かれている）。
- [ ] プロジェクト B 用の 10 秒動画をデスクトップに置く（ライブで取り込む用）。
- [ ] VRM を 2 体ライブラリに入れておく。
- [ ] 通知を切る（集中モード）、画面解像度 1920x1080 相当、文字サイズ確認。

## 1. 課題（30 秒）

「顔を出さずに vlog を出したい。でも今の方法は、モーキャプ機材か、1 秒に何十分もかかる手作業の合成。特に、机や楽器の“前後”が難しい。」

## 2. ライブ取り込み（60 秒）— プロジェクト B

1. ホームに 10 秒動画をドロップ → 動画情報と送信先（remote-win、RTX）を見せる → 「解析を始める」。
2. アップロード → 追跡の進捗。**待ち時間中に「人物を選ぶ」まで進める**（追跡が終わり次第）。人物を選び、VRM を割り当てる → 「アバターを描画」。
3. 「この先は数分かかるので、キューに入れて裏で続けます」→ ジョブパネルを見せる。

## 3. 完成済みプロジェクトで編集（120 秒）— プロジェクト A

1. ホームの最近のプロジェクトから A を開く → エディタで再生（置換結果、プロの画面構成）。
2. フレーム 120 で止める：「ギターがアバターの後ろに描かれている」。`U` で遮蔽物レイヤーを表示 → ギターをクリック → インスペクタで「前」→ **即座に直る**。
3. タイムラインの修正トラックで区間を見せ、端をドラッグして調整。`\` で元動画と見比べる。`⌘Z` で戻せることも見せる。

## 4. 書き出し（45 秒）

1. 書き出しタブ → 「手修正 1 件を反映」→ 書き出す（サーバーでフル解像度合成、約 1〜2 分）。
2. 待つ間に構成を説明（Mac ⇄ Tailscale ⇄ Windows の GPU サーバー、Windows 単体でも同じアプリ）。完了 → 再生。

## 5. 将来像（30 秒）

PRD のスコープ外（エンタープライズ：SSO・チーム・監査、ProRes / レイヤー書き出し、匿名化）を 1 枚で。「同じ ComputeBackend の差し替えで、オンプレの GPU やクラウドにも載る」。

## 障害時の切り替え

| 症状 | 判断 | 切り替え |
|---|---|---|
| サーバーに届かない（health が失敗） | 開始前なら 5 分だけ復旧を試みる | ライブ取り込み（§2）を省き、**サンプルプロジェクト**（オフライン）で §3 を行う。§4 は書き出し済み動画を再生 |
| アップロードが遅い | 30 秒で 50% に届かない | 取り込みは「始まるところ」までで止め、§3 へ |
| 書き出しが終わらない | 2 分を超えた | 書き出し済み動画（同じ修正を適用済み）を再生 |
| アプリが落ちる | — | 再起動（プロジェクトは自動保存済み）。再発したらサンプルで続行 |

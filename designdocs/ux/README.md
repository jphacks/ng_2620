# UX 設計

## 1. 体験の芯

> **「動画を入れて、アバターを選べば、物の前後まで正しい置換動画が出る。違っていたら、その物をクリックして直せる」**

- P1（配信者）には**迷わない 1 本道**（ウィザード）、P2（プロ）には**直せる編集画面**（エディタ）。同じプロジェクトで両方を行き来する。
- 推論は数分かかる。**待ち時間を「選ぶ時間」と「見る時間」に変える**：追跡が終わったらすぐ人物を選べ、メッシュや遮蔽判定は裏で進む。届いた結果から順にプレビューする。

## 2. 設計原則

| 原則 | 具体 |
|---|---|
| **非破壊** | ソース動画は変更しない。手修正は上書き情報として保存し、いつでも「自動」に戻せる。元に戻す / やり直し（⌘Z / ⇧⌘Z） |
| **状態が常に見える** | 画面下のステータスバーに接続先・キュー・実行中のジョブ（段階と %）を常時表示。プロジェクトの「再描画が必要」「再書き出しが必要」をバッジで |
| **段階的開示** | ウィザードは必要最小限（取り込み・人物・アバター・書き出し）。詳細（仕上げパラメータ、レイヤー表示、ユニットの判定理由）はエディタのインスペクタに |
| **結果で比べる** | 修正の前後・元動画との比較は、合成結果の画面上で（分割表示・A/B 切替）。数値は補助 |
| **プロのツールの作法** | ダークテーマ、パネル（左：プロジェクト / キャスト、中央：ビューア、右：インスペクタ、下：タイムライン）、キーボード操作（J/K/L、←/→、I/O） |
| **待たせない操作** | クリックから 100ms 以内に反応（選択・ハイライト）。手修正のプレビュー反映 0.5 秒以内 |
| **失敗を説明する** | エラーは「何が起きたか・なぜ・どうすればよいか」を 1 文ずつ。ログは折りたたみで |
| **信頼の表示** | VRM のライセンス（作者・商用可否）を割当時に表示。どのサーバーに動画を送るかを取り込み時に明示 |

## 3. 情報設計

```
アプリ
├─ ホーム（ワークスペース外）
│   ├─ 新規プロジェクト（動画をドロップ）
│   ├─ 最近のプロジェクト
│   ├─ サンプルを開く
│   └─ 接続状態（どの GPU サーバーにつながっているか）
├─ プロジェクト（ワークスペースを上部タブで切替）
│   ├─ 取り込み（ウィザード）  1 動画 → 2 解析 → 3 キャスト → 4 描画
│   ├─ 編集（エディタ）        ビューア / タイムライン / インスペクタ / キャスト / レイヤー
│   └─ 書き出し                設定 → 実行 → 完了（Finder で表示）
├─ ジョブパネル（どこからでも開ける）  キュー、進捗、ログ、取り消し、再試行
└─ 設定                          接続プロファイル、アバターライブラリ、一般（言語・キャッシュ）
```

## 4. 主要フロー

### 4.1 初回（P1：配信者）

1. ホームに動画をドロップ → 検証（30 秒・1920px）→ プロジェクト名を自動で付けて作成。
2. 「この動画を <接続先> に送って解析します」を確認 → 解析開始。アップロード → 解析の進捗がウィザード上部に出る。
3. 約 1〜2 分で人物一覧が出る（追跡マスクの動画プレビュー付き）。自分を選び、アバターを割り当てる（ライブラリから、または .vrm をドロップ）。
4. 「アバターを描画」→ 解析の残り（メッシュ・遮蔽判定）が終わると自動で描画が始まる。待つ間、メッシュのプレビューを再生できる。
5. 描画が終わると自動でエディタへ。プレビューを再生 → そのまま「書き出し」。

### 4.2 修正（P2：プロ）

1. エディタで再生し、物の前後が違う箇所で止める。
2. ビューアで「遮蔽物」レイヤーを表示（`U`）→ ユニットがハイライトされる。違っている物をクリック。
3. インスペクタに「この物体と <人物名> の関係：自動（後ろ）」が出る。「前」を選ぶ → 適用区間（既定はその物体が人物と重なる区間）を確認 → 即座にプレビューに反映。
4. タイムラインの修正トラックに区間が帯で表示される。区間の端をドラッグして調整できる。
5. 書き出しで修正が反映される。

### 4.3 待ち時間の体験（キュー）

- ジョブはキューに入り、アプリを閉じてもサーバーで続く。再び開くと状態を復元。
- 完了時に OS 通知（アプリが背面のとき）とトースト。複数プロジェクトを順に投入できる。

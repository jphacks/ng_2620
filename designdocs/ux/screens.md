# 画面設計

ウィンドウ最小サイズ 1280x800。ダークテーマ（背景 `#1e1e1e`、パネル `#252526`、アクセント `#4f8cff`）。色・余白・角丸は `presentation/shared/tokens.css` の CSS 変数で定義する。

## S0 共通の枠（F15）

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ ● ● ●  vvlog   カフェで弾き語り ▾     [ 取り込み | 編集 | 書き出し ]        ⚙  │ ← タイトルバー（ワークスペース切替）
├──────────────────────────────────────────────────────────────────────────────────────┤
│                                   （ワークスペース）                                   │
├──────────────────────────────────────────────────────────────────────────────────────┤
│ ● remote-win (RTX 5060 Ti)  │ 解析中 track 62% 残り約 1 分 │ キュー 2 │ 保存済み  │ ⌃J  │ ← ステータスバー
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- ステータスバー左：接続状態（●緑 = 接続、●黄 = 再接続中、●灰 = オフライン）。クリックで接続設定。
- 中央：実行中ジョブの段階と %。クリックでジョブパネル（右から出るドロワー）。
- 右：保存状態（「保存済み」/「保存中…」/「保存に失敗」）。

```
┌────────────────────────────────────────────────────────────────────┐
│  vvlog                                                      │
│  ┌──────────────────────────────┐   最近のプロジェクト               │
│  │                              │   ┌────┐ カフェで弾き語り  2 分前  │
│  │   動画をここにドロップ        │   │thumb│ 描画済み・修正 3 件      │
│  │   または [ファイルを選ぶ]     │   └────┘                          │
│  │   mp4 / mov・3 分・1920px まで │   ┌────┐ 公園 vlog       昨日    │
│  └──────────────────────────────┘   │thumb│ 解析中 45%               │
│  [ サンプルを開く ]                  └────┘                          │
│  接続先: ● remote-win  [変更]                                        │
└────────────────────────────────────────────────────────────────────┘
```

| 状態 | 表示 |
|---|---|
| 初回（最近が空） | 右側に「まずはサンプルを開いてみましょう」とサンプルのカード |
| 接続なし | 接続先の行が「● 未接続 — サンプルは開けます」＋[接続を設定] |
| ドロップしたファイルが制約外 | ドロップ領域が赤枠になり、理由（例：「201 秒あります。180 秒以下にトリミングしてください」）を表示 |

### S2-4 描画

- ビューアの上でマウスを動かすと、カーソル下のユニットを薄くハイライト（遮蔽物レイヤーが OFF でも、`Alt` 押下中はハイライト）。クリックで選択。
- 選択中のユニットは輪郭線（アクセント色）で表示し、インスペクタに人物ごとの関係を出す（ターゲットが複数なら人物ごとに行）。
- 修正トラックの帯はドラッグで区間を変更、`Delete` で削除（＝自動に戻す）。
- 「再書き出しが必要」バッジ：前回の書き出し以降に修正が変わったとき、上部の「書き出し」タブに点を付ける。

| 状態 | 表示 |
|---|---|
| レイヤー未取得（描画前） | ビューアは元動画＋追跡マスク。インスペクタに「アバターを描画すると編集できます」＋[描画] |
| レイヤーのダウンロード中 | ビューア上部に細い進捗バー。届いた範囲だけ再生可能（タイムラインに取得済み範囲を表示） |
| オフライン | 編集はそのまま可能。書き出しタブに「接続すると書き出せます」 |

## S5 ジョブパネル（F05）

右からのドロワー。サーバーのキュー全体（自分のプロジェクトは強調）、各ジョブの段階・%・経過時間、[取り消し]、失敗時は [再試行] [ログ]。

## S6 設定（F03・F07・F15）

- 接続：プロファイル一覧（名前、種別 ローカル/リモート、URL、トークン、[接続テスト]）。テスト結果に GPU 名・VRAM・キュー長。
- アバターライブラリ：グリッド表示（サムネイル・名前・作者・ライセンス）。[.vrm を追加]、削除。
- 一般：キャッシュの場所と容量、[キャッシュを消す]、言語（日本語のみ）。

# 操作仕様と文言

| キー | 動作 | 画面 |
|---|---|---|
| `Space` | 再生 / 停止 | エディタ |

| `←` / `→` | 1 フレーム戻る / 進む（`⇧` 併用で 10 フレーム） | エディタ |
| `Home` / `End` | 先頭 / 末尾 | エディタ |

| `H` | 隠れマスクの表示切替 | エディタ |

| `Alt`（押している間） | カーソル下の遮蔽物ユニットをハイライト | エディタ |

## 2. 前後関係の手修正（F10）の操作詳細

1. **選ぶ**：ビューアでクリックした画素のユニット（`units[f](x)`）を選択。0 ならターゲット人物の上かを見て「人物 n のアバター」を選択（インスペクタに「物体ではありません」とヒント）。
2. **既定の区間**：選んだユニットの、選択中の人物との `overlapFrames`。無ければユニットの `frames`。
3. **前 / 後ろ / 自動**：インスペクタのラジオか `F` / `B` / `A`。「前」「後ろ」は修正を 1 件追加（同じ人物・ユニット・区間が重なる既存の修正は置き換え）。「自動」は該当区間の修正を削除。
4. **対象の人物**：ターゲットが 1 人なら自動。複数なら、インスペクタに人物ごとの行を出す（既定はクリック位置にアバターがある人物）。
5. **区間の調整**：タイムラインの修正トラックで帯の端をドラッグ、または `I` / `O`。
6. **反映**：修正の追加・変更から 0.5 秒以内にビューアを再合成（再生中も）。
7. **元に戻す**：追加・変更・削除の 1 操作が 1 段。履歴は 100 段まで、プロジェクトを閉じると消える。

## 3. 再生（F09）

- 再生はプロキシ解像度で 30fps を目標。フレームのデコードが間に合わないときはフレームを飛ばす（音声は再生しない。P1 で元動画の音声を同期）。
- 先読み：再生ヘッドの前後 60 フレームを `ImageBitmap` で保持（LRU、上限 300 フレーム）。
- スクラブ中は最も近い取得済みフレームを即表示し、止まった時点で正確なフレームに差し替える。

## 4. ドラッグ＆ドロップ

| ドロップ先 | 受け付けるもの | 動作 |
|---|---|---|
| ホーム | 動画ファイル 1 つ | 新規プロジェクト |
| キャストの人物行 | `.vrm` | ライブラリに取り込み、その人物に割当 |
| 設定 > アバターライブラリ | `.vrm`（複数可） | 取り込み |
| それ以外 | — | 無視（カーソルを禁止表示） |

## 5. エラー文言

形式：**見出し（何が起きたか）＋ 本文（なぜ／どうすれば）＋ 操作**。エラーコードは [contracts §2.3](../architecture/contracts.md#23-エラー)。

| コード | 見出し | 本文 | 操作 |
|---|---|---|---|
| `UNAUTHORIZED` | サーバーに接続できません | トークンが正しくないようです。接続設定を確認してください。 | [接続設定] |
| ネットワーク断 | サーバーとの接続が切れました | 処理はサーバーで続いています。再接続を試みています… | [再試行] |
| `MEDIA_TOO_LONG` | 動画が長すぎます | {duration} 秒あります。30 秒以下に切り出してから取り込んでください。 | [別の動画を選ぶ] |
| `MEDIA_TOO_LARGE` | 解像度が大きすぎます | {w}x{h} です。長辺 1920px 以下に縮小してください。 | [別の動画を選ぶ] |
| `MEDIA_UNSUPPORTED` | この形式は読み込めません | mp4 / mov（H.264 / HEVC）の動画を選んでください。 | [別の動画を選ぶ] |
| `NO_PERSON_FOUND` | 人物が見つかりませんでした | 人物が大きく、はっきり映っている動画でお試しください。 | [別の動画を選ぶ] |
| `GPU_OOM` | GPU のメモリが足りませんでした | 他の処理が終わってから再試行するか、短い動画でお試しください。 | [再試行] [ログ] |
| `PIPELINE_FAILED` | 処理中にエラーが起きました | {stage} の段階で失敗しました。再試行しても直らない場合はログを共有してください。 | [再試行] [ログをコピー] |
| `INTERRUPTED` | 処理が中断されました | サーバーが再起動しました。もう一度実行してください。 | [再試行] |
| `AVATAR_INVALID` | この VRM は使えません | VRM として読み込めないか、必要なボーンがありません。 | [別の VRM を選ぶ] |
| 保存失敗 | プロジェクトを保存できません | ディスクの空き容量と、フォルダへの書き込み権限を確認してください。 | [再試行] [別の場所に保存] |

## 6. 通知

- ジョブ完了・失敗：アプリが前面ならトースト（5 秒、失敗は閉じるまで残す）、背面なら OS 通知（Tauri `notification` プラグイン）。
- 文言例：「解析が完了しました — 人物を 2 人見つけました」「描画が完了しました — エディタで確認できます」「書き出しが完了しました — カフェで弾き語り_001.mp4」。

# VirtualTwin ロゴの使い方

正（ソース）は `designdocs/brand/` の SVG。詳しい仕様と色コードは `designdocs/brand/README.md`（アセットガイドライン）。迷ったら先にそれを読む。

## 1. 版を選ぶ（背景で決まる）

| 背景 | カラー | 単色 |
|---|---|---|
| 白・明るい背景 | `designdocs/brand/color/` | `designdocs/brand/mono-black/` |
| 暗い背景・暗い写真の上 | `designdocs/brand/color-dark/` | `designdocs/brand/mono-white/` |

- 中間の明るさの背景（鮮やかな緑・黄色など）は、縁取りと同化するので避ける。使うなら白い板の上に置く。
- 1 色印刷・スタンプ・刺繍など、色が使えない用途は単色。

## 2. ロゴの種類を選ぶ

ファイル名は `virtualtwin-<種類><版の印>.svg|png`。版の印は、カラー = なし、`-dark`、`-mono-black`、`-mono-white`。

| 種類 | `<種類>` | 使う場面 |
|---|---|---|
| 正方形マーク | `mark` | アプリ・SNS のアイコンなど、正方形の枠 |
| 横並び | `logo-horizontal` | ヘッダー、スライドのタイトル、README の見出し |
| 縦並び | `logo-vertical` | 表紙、ポスター、幅の狭い場所 |
| 文字ロゴ | `wordmark` | 名前だけが要る場所（マークが近くに別にある） |
| 丸だけ | `mark-circles` | 横並び・縦並びの部品。単体では基本使わない |

迷ったら、横長なら横並び、正方形に近ければ縦並び、枠が正方形ならマーク。

## 3. 形式

- Web・ドキュメントは **SVG** を優先。SNS やスライドなど SVG が使えない所だけ PNG（透過、`<版>/png/`）。
- PNG のサイズ: マーク 1024px、文字ロゴ・横並び 2400px 幅、縦並び 1600px 幅。別サイズが要るときは SVG から書き出す（元を拡大しない）。
- 正方形マークのアイコン用サイズ違いは `color/png/mark-sizes/`、`.ico` と `.icns` は `color/icon/`。アプリのアイコンに使うときは `virtualtwin-app-icon` スキルを使う。

## 4. 余白と最小サイズ

- 周りの余白: 黄色い子（右の黄色い丸）の直径の 1/4 以上。
- 最小サイズの目安: マーク 48px 角、文字ロゴ 幅 160px、横並び 幅 240px、縦並び 幅 160px（目安。小さくて読めなければ大きくする）。

## 5. やってはいけないこと

- 色を変える（左右の緑・黄色の入れ替えも不可）。ロゴの色が要る場面は、版を選ぶ（暗い背景用、単色）。
- 引き伸ばす、傾ける、回す。
- 白い子と黄色い子の重なり方・位置、文字ロゴの左右の分け方を変える。
- 影や縁取りを足す・外す・ぼかす。
- 写真や模様の上に直接置いて見えにくくする。
- 正方形マークの背景（緑の板）を外して丸だけにし、マークとして使う。
- 角を丸めない正方形版は、まだ無い。OS が角を丸める用途（iOS など）に、角丸の透過マークをそのまま渡さない。

## 6. ロゴを新しく作る・直すとき

- 既存の SVG をコピーして編集せず、まず `designdocs/brand/README.md` の「まだないもの」を確認する。暗い背景用の作り込み、角を丸めない版、ファビコン用の簡略版、単色の細部の検証は、未対応。
- 文字ロゴは Arial Rounded Bold（macOS 標準）を元にアウトライン化している。**商用や配布物に使う前に、フォントのライセンスを確認する**。
- SVG にはグラデーション・マスク・クリップが入っている。3・4（横並び・縦並び）は、文字ロゴと丸だけを入れ子で組んでいる。Illustrator で開くと見え方が変わることがあるので、確認する。
- ロゴを足した・変えたら、`designdocs/brand/README.md` も合わせて更新する。
